## About peaq

peaq is a layer 1 network purpose built for DePIN (Decentralized Physical Infrastructure Networks), enabling real world machines, vehicles, devices, and robots to connect and transact in Web3. Built on Substrate within the Polkadot ecosystem, peaq provides identity, access control, and payment functions for physical infrastructure applications.
